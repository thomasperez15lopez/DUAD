##### 2

Create a program that creates a dictionary using two lists of the same size, using one for its keys, and the other for its values.

Examples:
list_a = ['first_name', 'last_name', 'role']
list_b = ['Alek', 'Castle', 'Software Engineer']
→ {'first_name': 'Alek', 'last_name': 'Castle', 'role': 'Software Engineer'}


##### 3
Create a program that uses a list to remove keys from a dictionary.

Examples:
list_of_keys = ['access_level', 'age']
employee = {'name': 'John', 'email': 'john@ecorp.com', 'access_level': 5, 'age': 28}
→ {'name': 'John', 'email': 'john@ecorp.com'}
